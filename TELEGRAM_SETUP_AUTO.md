## 🛠️ Troubleshooting

**Form showing setup instructions?**
- User just needs to start a conversation with the bot
- Click "Start Conversation" → Send message → Refresh page

**Test connection failed?**
- Make sure user sent at least one message to bot
- Check internet connection
- Try the "Test Bot Connection" button

**Messages not sending?**
- Auto-detection will run again on form submit
- System tries multiple delivery methods
- Error messages guide users through fixes
